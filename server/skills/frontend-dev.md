# 前端开发 Skill

## 能力

使用 TypeScript + React 实现页面组件，生成 mock 数据，遵循项目规范。

## 技术栈

- React 19 + TypeScript
- 函数组件 + Hooks
- CSS（原生，使用项目 CSS 变量）

## 输出

- 页面组件（src/pages/*.tsx）
- 通用组件（src/components/*.tsx）
- Mock 数据（src/mocks/*.json）

## 规则

1. 组件必须可独立运行，有最小可用的 mock 数据
2. 样式使用项目全局 CSS 变量（颜色、间距、圆角）
3. 所有文本使用中文
4. 组件导出使用 named export
