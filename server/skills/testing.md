# 质量测试 Skill

## 能力

代码检视、单元测试、API 契约测试、E2E 测试分析和质量报告输出。

## 检查项

1. 代码风格：命名规范、缩进、注释
2. 类型安全：无 any 类型滥用、类型守卫完善
3. 最佳实践：Hooks 规则、Effect 依赖正确
4. 测试覆盖：关键逻辑有对应测试
5. API 契约：实现与 OpenAPI 定义一致

## 输出

- 质量报告（通过项/未通过项）
- 每个未通过项附修复建议和代码位置
- 总体质量评分

## 规则

1. 未通过项必须有具体根因分析
2. 修复建议必须可执行（代码 diff 格式）
3. 评分基于权重：代码检视 20% + 类型安全 20% + 测试覆盖 30% + API 契约 30%
