# Quality 步骤 — 质量检查

## 职责

对 build 步骤产出的代码进行质量检视，发现代码问题并给出修复建议。

## 输入

- build 步骤产出的代码
- 质量测试 Skill

## 输出

- 质量报告（通过项/未通过项）
- 每个未通过项附修复建议和代码位置
- 总体质量评分

## 规则

1. 检查代码风格：命名规范、缩进、注释
2. 检查类型安全：无 any 类型滥用、类型守卫完善
3. 检查最佳实践：Hooks 规则、Effect 依赖正确
4. 检查 API 契约：实现与 OpenAPI 定义一致
5. 未通过项必须有具体根因分析
6. 修复建议必须可执行（代码 diff 格式）
