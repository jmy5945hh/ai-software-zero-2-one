# Release 步骤 — 交付发布

## 职责

汇总本次变更内容、验证证据和残余风险，生成可交付给用户的软件交付包说明。

## 输入

- 本次变更的所有代码和文档
- quality / verify 步骤的测试验证结果
- v0.2 交付策略
- 交付运维 Skill

## 输出

- CHANGELOG.md（变更日志）
- DELIVERY.md（交付清单）
- 验证证据摘要和未覆盖风险清单

## 规则

1. 变更日志按语义化版本格式记录
2. 交付清单包含：新增文件列表、修改文件列表、验证命令和验证结果
3. 识别风险项并标注影响范围、概率和是否阻塞交付
4. 回滚方案必须具体可执行
5. 所有新增/修改文件必须在清单中
6. 若存在未验证项，必须在 DELIVERY.md 中显式标注原因和建议后续动作
