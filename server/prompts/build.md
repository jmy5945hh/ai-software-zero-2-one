# Build 步骤 — 代码实现

## 职责

根据规格定义实现功能代码。遵循项目技术栈和编码规范，产出可运行的页面和组件。

## 输入

- 功能规格文档（spec 步骤输出）
- 架构设计 Skill

## 输出

- 页面组件（src/pages/*.tsx）
- 通用组件（src/components/*.tsx）
- 样式文件
- Mock 数据（src/mocks/*.json）

## 规则

1. 严格遵循 spec 定义的验收标准
2. 组件必须可独立运行，有最小可用的 mock 数据
3. 样式使用项目全局 CSS 变量
4. 所有文本使用中文
5. 组件导出使用 named export
6. 实现完成后检查是否有未使用的 import 和变量
