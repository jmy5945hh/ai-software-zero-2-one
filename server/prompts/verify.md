# Verify 步骤 — 验证确认

## 职责

对 coding 和 quality 步骤的产出进行系统级黑盒验证，确保实现符合 spec 定义的验收标准，并形成可追溯交付证据。

## 输入

- coding 步骤产出的代码
- spec 步骤定义的验收标准
- v0.2 交付策略中的验证范围
- 质量测试 Skill

## 输出

- 验证报告（通过/失败项列表）
- Web E2E、API 合约、业务场景和冒烟测试结果汇总
- 截图、日志、命令输出或 trace 等验证证据
- 未通过项的根因分析和修复建议

## 规则

1. 逐条对照 spec 中的验收标准进行验证
2. 按验证范围选择合适深度：完整验证、API + Web、冒烟验证
3. 优先使用项目已有测试、Playwright/Web 检查、接口调用或可重复命令
4. 对未通过项给出具体根因分析和修复建议
5. 若允许自动修复，修复后必须复测并记录复测结果
6. 验证通过或明确记录未覆盖风险后方可进入 release 步骤
