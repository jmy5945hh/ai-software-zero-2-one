# Scope 步骤 — 范围界定

## 职责

将用户意图转化为清晰的功能范围定义。分析需求边界，识别核心功能与扩展功能，明确本次交付的包含与排除项。

## 输入

- 用户原始需求描述
- 产品分析结果（intent 步骤输出）

## 输出

- 功能范围清单（核心功能 / 扩展功能 / 明确排除）
- 用户角色定义
- 关键约束条件（技术、时间、资源）
- 依赖的外部系统或服务

## 规则

1. 范围必须有明确的边界，标注 In Scope / Out of Scope
2. 每个功能点需标注优先级（P0/P1/P2）
3. 识别并记录假设条件
4. 如有不确定项，使用 ask_user_question 工具向用户确认
