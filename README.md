# ai-software-zero-2-one
用于验证AI Agent端到端生成完整软件的可行性

# 场景

招财银行北京分行运营门户系统，详见 PRD需求文档.md

## 关键功能模块

该Demo系统包含以下场景功能模块

- **首页**：轮播图、新闻中心、业务功能入口
- **CRUD表单**：面向信息数字化管理使用
- **审批流**：一个简单的业务审批操作流程
- **数据大屏**： 以可视化图表呈现数据
- **AI助手**： 集成大模型Chat问答能力
- **用户管理**： 一套完备的权限管理系统，可区分不同角色。
