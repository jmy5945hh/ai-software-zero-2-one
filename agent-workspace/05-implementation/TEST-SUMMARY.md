## 已发现的关键问题

### P0 级别（必须修复）

1. **数据级权限隔离缺失** (P0-001)
   - 问题：客户经理可以查看其他客户经理创建的拜访记录
   - 影响：数据泄露风险
   - 修复方案：在 `VisitService.list_visits()` 中添加数据过滤逻辑

### P1 级别（建议修复）

2. **审批列表 API 路径问题** (P1-001)
   - 问题：审批人员无法访问待审批列表
   - 影响：审批功能不可用
   - 修复方案：检查路由注册

3. **HTTP 状态码不统一** (P1-002)
   - 问题：部分错误场景状态码不一致（405 vs 422）
   - 影响：错误处理不规范
   - 修复方案：统一错误处理中间件
