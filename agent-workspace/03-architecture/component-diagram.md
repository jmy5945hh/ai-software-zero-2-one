# 招财银行北京分行运营门户 - 组件架构图

## 1. 系统组件概览

本系统采用前后端分离架构，主要包含前端应用、后端服务、数据库和外部服务四个主要部分。

- **React Core**: 应用的基础框架

## 6. 组件交互关系

### 6.1 前后端交互
- 前端通过RESTful API与后端进行数据交互
- 使用JWT进行身份验证和授权
- 前端状态管理与后端API同步

### 6.2 服务间交互
- 后端各服务模块通过内部API调用
- 数据访问层与数据库进行交互
- AI服务通过API调用外部LLM服务

### 6.3 外部集成
- 认证服务与银行内部身份认证系统集成
- 客户信息服务与银行核心系统集成
- 通知服务与银行内部消息系统集成
- AI服务与银行内部AI平台集成
