## 缺陷状态说明

| 状态 | 说明 |
|-----|-----|
| 待修复 | 缺陷已发现，等待开发人员修复 |
| 修复中 | 开发人员正在修复缺陷 |
| 已修复 | 开发人员已完成缺陷修复，等待测试人员验证 |
| 已验证 | 测试人员已验证缺陷修复，确认问题已解决 |
| 已关闭 | 缺陷已修复并验证通过，缺陷生命周期结束 |

## 严重程度说明

| 严重程度 | 说明 |
|---------|-----|
| 高 | 影响系统核心功能，导致系统无法正常运行或数据丢失 |
| 中 | 影响系统部分功能，或影响用户体验，但不影响系统核心功能 |
| 低 | 仅影响系统外观或次要功能，不影响系统正常运行 |

## 优先级说明

| 优先级 | 说明 |
|-------|-----|
| 高 | 需要立即修复，否则影响系统上线或用户使用 |
| 中 | 建议在当前迭代修复，否则影响系统质量 |
| 低 | 可以在后续迭代修复，或作为优化项处理 |
