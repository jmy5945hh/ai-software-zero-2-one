## 2. 登录模块

### P-01: 登录页面

**用途**: 用户通过账号密码登录系统

**访问角色**: 未登录用户

**主要元素**:
- Logo 和系统名称
- 登录表单（账号输入框、密码输入框、登录按钮）
- 错误提示信息
- 版权信息

**布局说明**:

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│                    [Logo + 系统名称]                        │
│                                                            │
│                  ┌──────────────────┐                      │
│                  │  登录表单         │                      │
│                  │                   │                      │
│                  │  账号: [______]  │                      │
│                  │                   │                      │
│                  │  密码: [______]  │                      │
│                  │                   │                      │
│                  │    [登录按钮]    │                      │
│                  │                   │                      │
│                  │  错误提示: _____  │                      │
│                  └──────────────────┘                      │
│                                                            │
│                    版权信息 © 2026                         │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**交互行为**:
- 输入框支持 Tab 键切换
- 按 Enter 键提交登录表单
- 登录失败时，在表单上方显示错误提示
- 登录成功后，跳转到首页

**数据来源**:
- 表单提交: POST /api/login
- 用户信息: 从后端获取用户角色和权限

**状态变化**:
- 初始状态: 显示空表单
- 提交中状态: 登录按钮显示 loading，禁用按钮
- 失败状态: 显示错误提示，清空密码框
- 成功状态: 跳转到首页

## 3. 首页模块

### P-02: 首页

**用途**: 展示公告、新闻和功能入口，用户登录后的默认页面

**访问角色**: 所有角色

**主要元素**:
- 轮播图组件（图片、标题、描述）
- 新闻列表（标题、发布时间、摘要）
- 功能入口卡片（根据角色动态展示）

**布局说明**:

```
┌────────────────────────────────────────────────────────────────────┐
│  顶部导航栏（Logo + 面包屑 + 用户菜单）                              │
├────────────────────────────────────────────────────────────────────┤
│  左侧导航 │                                                        │
│  (可折叠) │        ┌────────────────────────────────────────┐     │
│           │        │           轮播图组件                     │     │
│           │        │  [图片1]  [图片2]  [图片3]             │     │
│           │        └────────────────────────────────────────┘     │
│           │                                                        │
│           │        ┌────────────────────────────────────────┐     │
│           │        │           新闻列表                       │     │
│           │        │  ───────────────────────────────────    │     │
│           │        │  1. 新闻标题1                2026-01-08  │     │
│           │        │     新闻摘要...                         │     │
│           │        │  ───────────────────────────────────    │     │
│           │        │  2. 新闻标题2                2026-01-07  │     │
│           │        │     新闻摘要...                         │     │
│           │        └────────────────────────────────────────┘     │
│           │                                                        │
│           │        ┌────────────────────────────────────────┐     │
│           │        │           功能入口                       │     │

│           │        └────────────────────────────────────────┘     │
└───────────┴────────────────────────────────────────────────────────┘
```

**交互行为**:
- 轮播图自动轮播（3秒切换）
- 支持手动点击轮播图指示器切换
- 点击新闻标题，跳转到新闻详情页
- 点击功能入口卡片，跳转到对应功能页面

**数据来源**:
- 轮播图: GET /api/carousels
- 新闻列表: GET /api/news?status=published
- 功能入口: 根据用户角色动态加载

**状态变化**:
- 初始状态: 显示 loading 占位
- 加载完成: 显示轮播图和新闻
- 无数据: 显示"暂无内容"提示

- 点击"编辑"按钮，跳转到拜访记录编辑页面（仅客户经理，仅自己的记录）

- 拜访记录列表: GET /api/visit-records

- 成功状态: 显示成功提示，跳转到列表或详情页
- 失败状态: 显示错误提示，停留在当前页面
