# 线框图概览

## 1. 设计原则

### 1.1 布局原则

- **简洁明了**：界面设计简洁，信息层次清晰，避免不必要的装饰
- **一致性**：各页面采用统一的布局结构、组件样式和交互方式
- **响应式设计**：适配不同屏幕尺寸，优先保证桌面端体验
- **角色适配**：根据不同角色显示相应的功能和信息

### 1.2 色彩方案

- **主色调**：银行蓝色系（象征专业、信任）
- **辅助色**：浅灰色（用于背景和分隔线）
- **强调色**：绿色（用于成功状态）、红色（用于错误状态）、黄色（用于警告状态）
- **文字颜色**：深灰色（主文字）、中灰色（辅助文字）、浅灰色（提示文字）

### 1.3 字体方案

- **标题**：黑体，16-24px
- **正文**：宋体或微软雅黑，14px
- **辅助文字**：12px
- **按钮文字**：14px，粗体

## 2. 通用组件

### 2.1 导航组件

- **顶部导航栏**：固定在页面顶部，包含系统Logo、主导航菜单、用户信息和AI助手入口
- **侧边导航栏**：可选，用于展开式菜单（在大屏设备上可固定显示）
- **面包屑导航**：显示当前页面位置，方便用户返回上一级

### 2.2 表单组件

- **输入框**：带标签，支持必填项标记、占位符提示和错误信息显示
- **下拉选择框**：支持单选和多选，带搜索功能（选项较多时）
- **日期选择器**：支持日期范围选择
- **按钮**：主要操作按钮（蓝色）、次要操作按钮（白色边框）、危险操作按钮（红色）

### 2.3 信息展示组件

- **卡片**：用于模块化展示信息，包含标题和内容区域
- **列表**：用于展示多条记录，支持排序、筛选和分页
- **表格**：用于结构化展示数据，支持列排序和筛选
- **图表**：折线图、柱状图、饼图等，用于数据可视化

### 2.4 反馈组件

- **提示框**：成功、错误、警告、信息四种类型
- **加载状态**：页面加载、数据提交时显示
- **确认对话框**：重要操作前的确认提示

## 5. 交互规范

- **悬停效果**：按钮、链接、可点击元素在鼠标悬停时有明显的视觉反馈
- **点击效果**：按钮点击时有按压效果
- **表单验证**：实时验证，失去焦点时显示错误信息
- **加载状态**：数据加载时显示加载动画，避免用户重复操作
- **页面切换**：平滑过渡，避免突兀跳转

## 6. 无障碍设计

- **键盘导航**：支持键盘Tab键导航和Enter键操作
- **屏幕阅读器支持**：语义化HTML结构，支持ARIA属性
- **颜色对比度**：确保文字与背景的对比度符合无障碍标准
- **字体大小**：支持浏览器字体大小调整
