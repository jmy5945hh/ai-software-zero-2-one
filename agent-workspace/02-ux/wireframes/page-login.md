# 登录页面线框图

## 1. 页面概述

登录页面是用户进入系统的第一个入口，用于验证用户身份，确保系统安全访问。

## 2. 页面布局

|  +-----------------------------------------------------+  |
|  |                                                     |  |
|  |                     登录表单                        |  |
|  |  +-------------------------------------------------+  |  |
|  |  |  账号:                                          |  |  |

## 3. 页面元素说明

### 3.1 系统标识区

- **系统Logo**：显示银行或系统的Logo
- **系统名称**：显示完整的系统名称"招财银行北京分行运营门户系统"
- **位置**：页面顶部居中

### 3.2 登录表单区

- **表单容器**：白色背景，带阴影效果，居中显示
- **宽度**：400px（响应式调整）
- **间距**：各元素间距16px

### 3.3 输入字段

#### 账号输入框
- **标签**："账号:"（必填）
- **类型**：文本输入框
- **占位符**："请输入您的账号"
- **验证**：失去焦点时验证格式
- **错误提示**：格式不正确时显示"请输入有效的账号"

#### 密码输入框
- **标签**："密码:"（必填）
- **类型**：密码输入框
- **占位符**："请输入您的密码"
- **可见性切换**：右侧显示"显示/隐藏"按钮，点击切换密码可见性
- **验证**：失去焦点时验证（至少6位）
- **错误提示**：密码长度不足时显示"密码长度不能少于6位"

### 3.4 操作按钮

#### 登录按钮
- **文本**："登录"
- **类型**：主要按钮（蓝色背景，白色文字）
- **宽度**：100%
- **高度**：40px
- **状态**：
  - 正常状态：可点击
  - 悬停状态：背景色加深
  - 禁用状态：当必填项未填写时禁用
  - 加载状态：点击后显示加载动画

### 3.5 辅助链接

#### 忘记密码链接
- **文本**："忘记密码?"
- **位置**：登录按钮下方，右侧对齐
- **样式**：蓝色文字，下划线
- **功能**：点击跳转到密码重置页面（本系统暂不实现，可显示提示信息）

### 3.6 反馈区域

#### 错误提示区域
- **位置**：登录按钮下方
- **样式**：红色文字，左侧带警告图标
- **内容**：根据登录结果显示不同提示
  - "账号或密码错误，请重新输入"
  - "账号已锁定，请联系管理员"
  - "系统繁忙，请稍后重试"

## 4. 交互流程

### 4.1 正常登录流程

1. 用户访问系统登录页
2. 系统显示登录表单
3. 用户输入账号和密码
4. 用户点击"登录"按钮
5. 系统验证用户凭证
6. 验证成功，跳转至系统首页
7. 验证失败，显示错误提示

### 4.2 密码可见性切换

1. 用户点击密码框右侧的"显示/隐藏"按钮
2. 密码框类型切换为文本/密码
3. 按钮文字切换为"隐藏/显示"

### 4.3 表单验证

1. 用户输入账号，失去焦点时
   - 若为空，显示"请输入账号"
   - 若格式不正确，显示"请输入有效的账号"

2. 用户输入密码，失去焦点时
   - 若为空，显示"请输入密码"
   - 若长度不足6位，显示"密码长度不能少于6位"

3. 用户点击"登录"按钮时
   - 若账号或密码为空，显示相应的错误提示
   - 若格式不正确，显示相应的错误提示

## 5. 响应式设计

- **桌面端**：表单宽度固定为400px，居中显示
- **平板端**：表单宽度调整为80%，最大宽度400px
- **移动端**：表单宽度调整为90%，最大宽度400px

## 6. 无障碍设计

- **键盘导航**：支持Tab键导航，Enter键登录
- **屏幕阅读器**：支持ARIA属性，标签与输入框关联
- **颜色对比度**：文字与背景对比度符合WCAG标准
- **字体大小**：支持浏览器字体大小调整

## 7. 页面状态

### 7.1 初始状态
- 表单为空，登录按钮可点击
- 错误提示区域隐藏

### 7.2 输入状态
- 输入框获取焦点时，边框颜色变化
- 输入内容时，实时验证
- 错误信息在失去焦点时显示

### 7.3 加载状态
- 点击登录按钮后，按钮显示加载动画
- 登录过程中，表单不可编辑

### 7.4 错误状态
- 显示相应的错误提示信息
- 错误字段边框显示红色

### 7.5 成功状态
- 登录成功后，页面跳转到系统首页

## 8. 设计规范

- **颜色**：
  - 主色调：银行蓝色（#1E90FF）
  - 文字颜色：深灰色（#333333）
  - 错误颜色：红色（#FF4444）
  - 背景颜色：浅灰色（#F5F5F5）

- **字体**：
  - 标题：黑体，24px
  - 正文：微软雅黑，14px
  - 按钮文字：微软雅黑，14px，粗体

- **间距**：
  - 表单元素间距：16px
  - 页面边距：根据屏幕尺寸自适应

- **密码重置页**：暂不实现，点击"忘记密码"可显示提示信息
