# 交互规范

**文档版本**: v1.0
**创建时间**: 2026-01-08
**关联文档**: wireframes/overview.md, design-system.md
**负责人**: UX Designer

---

## 文档说明

本文档定义"招财银行北京分行运营门户系统"的通用交互模式，包括导航、表单、列表、反馈提示、加载状态等，确保全系统的交互一致性。

**设计原则**:
- 符合用户心智模型
- 保持交互一致性
- 提供及时反馈
- 预防用户错误

---

## 1. 导航模式

### 1.1 顶部导航栏

**用途**: 显示 Logo、面包屑导航和用户菜单

**布局**:

```
┌─────────────────────────────────────────────────────────────┐
│  Logo  |  首页 > 拜访管理 > 拜访记录  |   [用户头像] 用户名 ▼│
└─────────────────────────────────────────────────────────────┘
```

**组件说明**:

| 组件 | 交互行为 | 说明 |
| --- | --- | --- |
| Logo | 点击跳转到首页 | 固定在左侧 |
| 面包屑导航 | 点击任意节点跳转到对应页面 | 显示当前页面位置 |
| 用户菜单 | 点击展开下拉菜单 | 包含个人信息、退出登录 |

---

### 1.2 左侧主导航菜单

**用途**: 显示系统功能菜单，根据角色动态展示

**布局**:

```
┌─────────┐
│ Logo    │
│ ☰ 汉堡菜单图标（折叠时显示）
├─────────┤
│ 🏠 首页 │
│ ├─ 拜访管理│
│ │  ├─ 拜访记录│
│ │  └─ 拜访统计│
│ ├─ 礼品管理│
│ │  ├─ 礼品申请│
│ │  └─ 礼品审批│
│ └─ 数据大屏│
└─────────┘
```

**交互行为**:

**展开/折叠**:
- 点击折叠按钮，侧边栏在展开/折叠状态间切换
- 展开状态: 宽度 240px，显示图标 + 文字
- 折叠状态: 宽度 64px，仅显示图标
- 系统记住用户的侧边栏状态（localStorage）

**菜单展开/收起**:
- 点击一级菜单，展开/收起二级菜单
- 点击二级菜单，跳转到对应页面
- 当前页面对应的菜单项高亮显示

**菜单悬停**（折叠状态）:
- 鼠标悬停在菜单图标上，显示悬浮菜单
- 悬浮菜单显示图标 + 文字
- 悬浮菜单从侧边栏向右展开

---

### 1.3 面包屑导航

**用途**: 显示当前页面的层级路径，支持点击跳转

**格式**:

```
首页 > 一级菜单 > 二级菜单 > 当前页面
```

**示例**:

| 当前页面 | 面包屑导航 |
| --- | --- |
| 拜访记录列表 | 首页 > 拜访管理 > 拜访记录 |
| 拜访记录详情 | 首页 > 拜访管理 > 拜访记录 > 详情 |
| 拜访记录编辑 | 首页 > 拜访管理 > 拜访记录 > 编辑 |
| 礼品申请新增 | 首页 > 礼品管理 > 礼品申请 > 新增 |

**交互行为**:
- 点击面包屑中的任意节点，跳转到对应页面
- 首页节点固定为第一项
- 面包屑最多显示 4 级（超出部分省略为"..."）

## 2. 表单交互

### 2.1 表单布局

**单列表单**:

```
┌────────────────────────────────┐
│  字段名称 *                     │
│  [输入框]                       │
│                                │
│  字段名称                       │
│  [输入框]                       │
│                                │
│  [提交]  [取消]                 │
└────────────────────────────────┘
```

**双列表单**（适用于字段较多的情况）:

```
┌────────────────────────────────────────┐
│  字段名称 *     │  字段名称 *          │
│  [输入框]       │  [输入框]            │
│                                        │
│  字段名称       │  字段名称 *          │
│  [输入框]       │  [输入框]            │
│                                        │
│            [提交]  [取消]              │
└────────────────────────────────────────┘
```

---

### 2.2 输入框交互

**焦点状态**:
- 获得焦点: 显示蓝色边框，阴影效果
- 失去焦点: 恢复默认边框

**输入提示**:
- 占位符: 显示输入提示（如"请输入账号"）
- 输入内容: 占位符消失

**必填标识**:
- 必填字段: 字段名称后显示红色星号(*)
- 可选字段: 无特殊标识

**错误提示**:
- 位置: 字段下方
- 颜色: 红色
- 图标: 警告图标
- 内容: 具体的错误原因

**示例**:

```
正常状态:
  客户ID *
  [_________________]  ✓ 通过

焦点状态:
  客户ID *
  [_________________]  (蓝色边框)

错误状态:
  客户ID *
  [_________________]  ✗ 请输入客户ID
```

---

### 2.3 下拉选择框交互

**单选下拉框**:

```
  拜访方式 *
  [现场 ▼]  (点击展开选项)
          ├─ 现场
          ├─ 电话
          └─ 视频
```

**交互行为**:
- 点击下拉框，展开选项列表
- 点击选项，选中并收起列表
- 点击外部区域，收起列表
- 支持键盘上下箭头选择
- 支持键盘 Enter 确认

**多选下拉框**:

```
  参与人员
  [张三 ✓] [李三 ✓] [王五 □]  (点击展开选项)
```

**交互行为**:
- 点击下拉框，展开选项列表
- 点击选项，切换选中/未选中状态
- 已选项显示复选框和删除按钮
- 点击删除按钮，移除选项
- 点击外部区域，收起列表

---

### 2.4 日期选择器交互

**单日期选择**:

```
  计划拜访日期 *
  [2026-01-08]  (点击展开日历)
```

**交互行为**:
- 点击输入框，展开日历组件
- 点击日期，选中并收起日历
- 支持手动输入日期（格式: YYYY-MM-DD）
- 输入错误格式时，显示错误提示

**日期区间选择**:

```
  时间区间
  [2026-01-01] 至 [2026-01-31]
```

**交互行为**:
- 点击开始日期输入框，展开日历，选择开始日期
- 点击结束日期输入框，展开日历，选择结束日期
- 结束日期不能早于开始日期（校验）

---

### 2.5 表单提交

**提交前校验**:
- 检查所有必填字段是否填写
- 检查数据格式是否正确（如日期格式）
- 检查业务逻辑是否正确（如结束日期 >= 开始日期）
- 校验失败: 在对应字段下方显示错误提示
- 校验通过: 提交表单

**提交中状态**:
- 提交按钮显示 loading 图标
- 提交按钮文字: "提交中..."
- 提交按钮禁用
- 所有输入框禁用

**提交成功**:
- 显示成功提示（页面右上角或顶部）
- 跳转到列表页或详情页
- 重置表单（如果是新增）

**提交失败**:
- 显示错误提示（页面右上角或顶部）
- 保持表单内容
- 提交按钮恢复启用
- 输入框恢复启用

---

### 2.6 表单取消

**点击取消按钮**:
- 如果表单有修改，弹出确认对话框:
  ```
  确定要放弃修改吗？
  [确定] [取消]
  ```
- 如果表单无修改，直接返回上一页

**标准列表**:

```
┌────────────────────────────────────────────────────────────┐
│  筛选器:                                                  │
│  时间区间: [2026-01-01] 至 [2026-01-31]  [查询] [重置]    │
│  状态: [全部 ▼]                                           │
│                                                           │
│  [+ 新增] (有权限时显示)                                   │
│                                                           │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 字段1  │ 字段2  │ 字段3  │ 字段4  │ 操作           │  │
│  ├────────────────────────────────────────────────────┤  │
│  │ 数据1  │ 数据2  │ 数据3  │ 数据4  │ [详情] [编辑]  │  │

│                                                           │
│  共 20 条记录                              [< 1 2 3 >]   │
└────────────────────────────────────────────────────────────┘
```

---

### 3.2 筛选器交互

**筛选条件**:
- 支持单个字段筛选
- 支持多个字段组合筛选（AND 关系）

**查询按钮**:
- 点击"查询"按钮，根据筛选条件刷新列表

**重置按钮**:
- 点击"重置"按钮，清空所有筛选条件
- 自动刷新列表（显示全部数据）

**示例**:

```
筛选前:
  共 100 条记录

筛选后:
  时间区间: 2026-01-01 至 2026-01-31
  状态: 待审批
  共 15 条记录  (筛选结果)
```

---

### 3.3 列表排序

**排序交互**:
- 点击列标题，切换排序方式
- 排序方式: 升序 → 降序 → 无排序
- 排序列标题显示排序图标（↑ ↓）

**示例**:

```
点击"创建时间"列标题:
  第一次点击: 升序 ↑
  第二次点击: 降序 ↓
  第三次点击: 无排序
```

---

### 3.4 列表分页

**分页组件**:

```
[<] [< 1 2 3 4 5 ... 10 >] [>]

每页显示: [10 ▼] 条  共 100 条
```

**交互行为**:
- 点击页码，跳转到对应页
- 点击"<"按钮，跳转到上一页
- 点击">"按钮，跳转到下一页
- 切换每页显示数量，自动刷新列表

---

### 3.5 列表操作

**行内操作**:

| 操作按钮 | 交互行为 | 说明 |
| --- | --- | --- |
| 详情 | 点击跳转到详情页 | 查看详细信息（只读） |
| 编辑 | 点击跳转到编辑页 | 编辑信息（有权限时显示） |
| 删除 | 点击弹出确认对话框 | 确认后删除（有权限时显示） |
| 审批 | 点击打开审批弹窗 | 审批操作（审批人员显示） |

**批量操作**（待确认是否实现）:
- 复选框: 选中/取消选中行
- 批量删除: 选中多条记录后，点击批量删除按钮

## 4. 反馈提示

### 4.1 提示位置

**全局提示**（推荐）:
- 位置: 页面右上角
- 持续时间: 3秒
- 支持手动关闭

**局部提示**:
- 位置: 操作按钮上方
- 持续时间: 5秒

---

### 4.2 提示类型

**成功提示**:

```
✓ 操作成功
[关闭 ×]
```

- 颜色: 绿色背景
- 图标: ✓
- 自动关闭: 3秒后消失

**错误提示**:

```
✗ 操作失败，请重试
[关闭 ×]
```

- 颜色: 红色背景
- 图标: ✗
- 自动关闭: 5秒后消失

**警告提示**:

```
⚠ 请确认是否继续
[确定] [取消]
```

- 颜色: 黄色背景
- 图标: ⚠
- 不自动关闭，需要用户操作

**信息提示**:

```
ℹ 系统将于今晚 22:00 进行维护
[关闭 ×]
```

- 颜色: 蓝色背景
- 图标: ℹ
- 自动关闭: 5秒后消失

---

### 4.3 确认对话框

**用途**: 危险操作前确认（如删除、驳回等）

**布局**:

```
┌─────────────────────────────────┐
│         确认删除                 │
├─────────────────────────────────┤
│                                 │
│  确定要删除这条记录吗？           │
│  此操作不可恢复。                │
│                                 │
│            [取消] [确定]         │
└─────────────────────────────────┘
```

**交互行为**:
- 显示模态对话框，背景遮罩
- 点击"取消"按钮，关闭对话框
- 点击"确定"按钮，执行操作
- 点击遮罩区域，关闭对话框

## 6. 特殊交互

### 6.1 审批流程交互

**礼品审批流程**:

```
待审批 → 已通过 / 已驳回
```

**交互行为**:

**审批人员打开审批详情**:
- 显示申请详细信息
- 显示审批操作: "通过" / "驳回"

**选择"通过"**:
- 直接提交审批结果
- 申请状态变为"已通过"
- 进入礼品台账

**选择"驳回"**:
- 显示"驳回原因"输入框
- 驳回原因为必填字段
- 填写原因后提交
- 申请状态变为"已驳回"

**审批完成后**:
- 申请状态不可变更
- 列表中的"审批"按钮消失

---

### 6.2 状态流转交互

**拜访记录状态**（待确认）:

```
计划中 → 已拜访 → 营销成功 / 无意向
```

**礼品申请状态**:

```
待审批 → 已通过 / 已驳回
```

**交互行为**:
- 状态字段显示为彩色标签
- 不同状态使用不同颜色:
  - 待审批: 蓝色
  - 已通过: 绿色
  - 已驳回: 红色
- 状态标签不可点击，仅显示

---

### 6.3 AI 对话交互

**打开 AI 助理**:
- 点击右下角的圆形图标按钮
- 侧边栏从右侧滑入
- 显示欢迎语和快捷问题选项（待确认）

**对话交互**:
- 在输入框中输入问题
- 点击"发送"按钮或按 Enter 键发送
- 用户消息显示在对话历史中
- 显示"正在思考..."状态
- AI 回复后，显示在对话历史中
- 支持多轮对话，保留上下文

**关闭 AI 助理**:
- 点击"×"按钮，侧边栏滑出
- 点击侧边栏外部区域，关闭侧边栏
- 保持对话历史（待确认）

## 8. 响应式设计说明

**本系统仅支持 PC 端，无需响应式设计。**

**PC 端分辨率支持**:
- 最低支持分辨率: 1366 x 768
- 推荐分辨率: 1920 x 1080

**布局适配**:
- 内容区域自适应屏幕宽度
- 数据大屏在大屏幕下显示效果更佳

## 9. 可访问性

### 9.1 键盘导航

- 所有交互元素支持键盘操作
- Tab 键在可聚焦元素间切换
- Enter 键触发当前聚焦元素
- ESC 键关闭弹窗或取消操作

---

### 9.2 屏幕阅读器

- 所有图标添加 `aria-label` 属性
- 表单字段添加 `aria-label` 或 `aria-describedby` 属性
- 错误提示添加 `role="alert"` 属性
- 对话框添加 `role="dialog"` 属性

---

### 9.3 焦点可见性
