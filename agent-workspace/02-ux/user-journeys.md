# 用户旅程地图 - 招财银行北京分行运营门户系统

## 1. 客户经理用户旅程

### 主要目标
- 登记客户拜访和营销情况
- 提交营销礼品领用申请
- 查看个人拜访记录和礼品申请状态

### 用户旅程流程

#### 旅程1：登记客户拜访记录
1. **登录系统**
   - 用户打开系统，输入账号密码
   - 系统验证身份，加载客户经理角色菜单
   - 进入系统首页

2. **导航到客户拜访模块**
   - 点击左侧菜单"客户拜访管理"
   - 进入客户拜访列表页面
   - 点击"新增拜访记录"按钮

3. **填写拜访记录**
   - 输入客户ID、企业名称
   - 选择计划拜访日期
   - 选择拜访方式
   - 选择意向理财产品（多选）
   - 选择参与人员（默认包含当前用户）
   - 填写拜访备注
   - 点击"保存"按钮

4. **确认保存成功**
   - 系统显示保存成功提示
   - 返回客户拜访列表页面
   - 新增的记录出现在列表中

#### 旅程2：查看和管理个人拜访记录
1. **进入拜访记录列表**
   - 登录后点击"客户拜访管理"
   - 系统显示该用户创建或参与的拜访记录

2. **筛选和查询记录**
   - 使用筛选条件（时间区间、状态、企业名称等）
   - 点击"查询"按钮
   - 查看筛选结果

3. **编辑拜访记录**
   - 在列表中找到需要编辑的记录
   - 点击"编辑"按钮
   - 修改允许编辑的字段
   - 点击"保存"按钮

4. **导出数据**
   - 设置查询条件
   - 点击"导出Excel"按钮
   - 系统生成并下载Excel文件

#### 旅程3：提交礼品领用申请
1. **进入礼品申请模块**
   - 点击左侧菜单"礼品申请管理"
   - 进入礼品申请列表页面
   - 点击"新增礼品申请"按钮

2. **填写申请信息**
   - 系统自动填充申请人信息
   - 选择领用人（可选）
   - 添加礼品到申请列表（礼品名称、数量、单价）
   - 系统自动计算总金额
   - 选择计划领用日期（不能早于当前日期）
   - 选择目的类型（客户维护、营销活动、其他）
   - 关联客户拜访记录（可选）
   - 点击"提交申请"按钮

3. **确认提交成功**
   - 系统显示提交成功提示
   - 申请状态变为"待审批"
   - 返回礼品申请列表页面

#### 旅程4：查看个人礼品申请状态
1. **进入申请列表**
   - 点击"礼品申请管理"
   - 系统显示该用户提交的申请列表

2. **查看申请详情**
   - 点击申请记录查看详细信息
   - 查看礼品列表、总金额、申请日期等

3. **撤回待审批申请**
   - 找到状态为"待审批"的申请
   - 点击"撤回申请"按钮
   - 确认撤回操作

## 2. 运营人员用户旅程

### 主要目标
- 维护首页内容（轮播图、新闻）
- 查看运营数据
- 管理礼品台账

### 用户旅程流程

#### 旅程1：维护首页轮播图
1. **进入首页管理**
   - 登录后点击"首页管理"
   - 进入轮播图管理页面

2. **新增轮播图**
   - 点击"新增轮播图"按钮
   - 上传图片文件
   - 填写标题和跳转链接
   - 设置排序序号
   - 点击"保存"按钮

3. **编辑现有轮播图**
   - 在列表中找到需要编辑的轮播图
   - 点击"编辑"按钮
   - 修改相关信息
   - 点击"保存"按钮

4. **删除轮播图**
   - 在列表中找到需要删除的轮播图
   - 点击"删除"按钮
   - 确认删除操作

#### 旅程2：发布和管理新闻
1. **进入新闻管理**
   - 点击"首页管理" -> "新闻管理"
   - 进入新闻列表页面

2. **新增新闻**
   - 点击"新增新闻"按钮
   - 填写标题、摘要
   - 在富文本编辑器中编写内容
   - 选择发布状态（草稿/已发布）
   - 点击"保存"按钮

3. **编辑新闻**
   - 在新闻列表中找到需要编辑的新闻
   - 点击"编辑"按钮
   - 修改新闻内容
   - 点击"保存"按钮

4. **发布/下线新闻**
   - 选择需要操作的新闻
   - 点击"发布"或"下线"按钮
   - 确认操作

#### 旅程3：查看运营数据和礼品台账
1. **进入运营数据模块**
   - 点击左侧菜单"运营数据"
   - 进入数据大屏页面

2. **查看数据指标**
   - 浏览关键运营指标
   - 查看图表展示（折线图、柱状图、饼图）

3. **切换统计维度**
   - 选择时间维度（天/周/月）
   - 选择自定义时间范围
   - 查看更新后的图表

4. **查看礼品台账**
   - 点击"礼品台账"菜单
   - 查看礼品使用记录
   - 使用筛选条件查询特定数据
   - 导出台账数据

## 3. 审批人员用户旅程

### 主要目标
- 审批客户经理提交的礼品申请
- 查看礼品台账

### 用户旅程流程

#### 旅程1：审批礼品申请
1. **登录系统**
   - 输入账号密码登录
   - 系统加载审批人员角色菜单

2. **进入待审批列表**
   - 点击"礼品审批管理"
   - 系统显示分配给该审批人员的待审批申请
   - 申请按提交时间排序

3. **查看申请详情**
   - 点击申请记录查看详细信息
   - 查看礼品列表、总金额、申请人信息等

4. **审批操作**
   - 选择"通过"或"驳回"
   - 如果选择"驳回"，填写驳回原因（不少于10个字符）
   - 点击"确认审批"按钮
   - 系统记录审批人和审批时间

5. **确认审批结果**
   - 系统显示审批成功提示
   - 申请状态更新
   - 通知申请人审批结果

#### 旅程2：查看礼品台账
1. **进入礼品台账**
   - 点击"礼品台账"菜单
   - 进入台账列表页面

2. **筛选和查询**
   - 使用筛选条件（时间区间、礼品类型、领用人员等）
   - 点击"查询"按钮
   - 查看筛选结果

3. **查看统计信息**
   - 查看按礼品类型、时间区间的统计图表
   - 分析礼品使用趋势

## 4. 分行管理者用户旅程

### 主要目标
- 查看运营数据大屏
- 监控整体运营情况
- 查看礼品台账

### 用户旅程流程

#### 旅程1：查看运营数据大屏
1. **登录系统**
   - 输入账号密码登录
   - 系统加载管理者角色菜单

2. **进入数据大屏**
   - 点击"运营数据大屏"
   - 进入数据可视化页面

3. **查看关键指标**
   - 浏览客户拜访次数、营销成功次数、礼品领用数量等指标
   - 查看实时更新的数据（每5分钟刷新）

4. **切换统计维度**
   - 选择时间维度（天/周/月）
   - 选择自定义时间范围
   - 查看同比、环比数据

5. **数据钻取分析**
   - 点击图表中的数据点
   - 查看详细记录信息
   - 进行深入分析

6. **导出数据**
   - 点击"导出"按钮
   - 选择导出格式（PDF/Excel）
   - 下载导出文件

#### 旅程2：监控礼品使用情况
1. **进入礼品台账**
   - 点击"礼品台账"菜单
   - 查看全行礼品使用情况

2. **分析支出结构**
   - 查看按礼品类型分类的支出占比饼图
   - 分析支出结构合理性

3. **趋势分析**
   - 查看礼品使用趋势图表
   - 识别使用模式和异常情况

4. **生成报告**
   - 设置查询条件
   - 导出台账数据
   - 生成分析报告
