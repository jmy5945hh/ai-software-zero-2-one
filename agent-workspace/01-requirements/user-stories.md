# 用户故事文档 - 招财银行北京分行运营门户系统

## 1. 登录与首页模块

### US-001: 登录系统
**作为** 分行员工  
**我希望** 通过账号密码登录系统  
**以便** 安全访问与我角色匹配的功能

**详细描述**:
- 用户需要输入有效的用户名和密码才能访问系统
- 系统验证用户凭据后，根据用户角色加载相应的功能菜单
- 登录失败时提供明确的错误信息

### US-002: 查看首页信息
**作为** 登录用户  
**我希望** 在首页查看公告、新闻和功能入口  
**以便** 快速了解分行运营信息并进入业务功能

**详细描述**:
- 首页展示轮播图、新闻列表和功能入口
- 功能入口根据用户角色动态显示
- 提供系统使用快捷入口

### US-003: 维护首页内容
**作为** 运营人员  
**我希望** 维护首页轮播图和新闻内容  
**以便** 及时发布运营信息

**详细描述**:
- 运营人员可以新增、编辑、删除轮播图内容
- 运营人员可以发布、编辑、下线新闻内容
- 非运营人员仅能查看首页内容

## 2. 客户拜访与理财营销登记管理

### US-004: 登记客户拜访记录
**作为** 客户经理  
**我希望** 登记客户拜访和营销情况  
**以便** 规范记录日常营销活动

**详细描述**:
- 客户经理可以创建新的客户拜访记录
- 记录包含客户信息、拜访计划、参与人员、意向产品等
- 系统自动记录创建人和创建时间

### US-005: 管理个人拜访记录
**作为** 客户经理  
**我希望** 查看和修改我创建的拜访记录  
**以便** 更新营销进展

**详细描述**:
- 客户经理可以查看自己创建或参与的拜访记录
- 支持编辑拜访记录（部分字段在特定状态下不可编辑）
- 不支持物理删除，仅支持逻辑删除

### US-006: 查询拜访记录
**作为** 客户经理或运营人员  
**我希望** 按条件查询拜访记录  
**以便** 进行统计和分析

**详细描述**:
- 支持多种查询条件（时间、状态、客户、参与人员等）
- 查询结果支持分页显示
- 支持导出查询结果

## 3. 营销礼品领用审批管理

### US-007: 提交礼品领用申请
**作为** 客户经理  
**我希望** 提交营销礼品领用申请  
**以便** 合规使用营销资源

**详细描述**:
- 客户经理可以填写礼品申请单
- 申请单包含申请人、领用人、礼品列表、计划日期、目的等
- 提交后状态变为"待审批"，内容不可修改

### US-008: 查看个人礼品申请
**作为** 客户经理  
**我希望** 查看我的礼品申请记录和状态  
**以便** 了解审批进度

**详细描述**:
- 客户经理可以查看自己提交的申请记录
- 显示申请状态和审批结果
- 支持按状态筛选申请记录

### US-009: 审批礼品申请
**作为** 审批人员  
**我希望** 审批客户经理提交的礼品申请  
**以便** 控制礼品使用合规性

**详细描述**:
- 审批人员可以查看待审批的申请
- 可以选择通过或驳回申请
- 驳回时必须填写原因

### US-010: 查看礼品台账
**作为** 运营人员或管理者  
**我希望** 查看礼品使用台账  
**以便** 进行统计和管理

**详细描述**:
- 展示所有已审批的礼品使用记录
- 支持按条件筛选和统计
- 支持数据导出功能

## 4. 运营数据大屏

### US-011: 查看运营指标
**作为** 分行管理者  
**我希望** 在数据大屏查看关键运营指标  
**以便** 快速掌握整体运营情况

**详细描述**:
- 展示关键运营指标（拜访次数、营销成功次数、礼品领用数量等）
- 提供图表展示（折线图、条形图、饼图等）
- 数据来源于系统内部数据

### US-012: 切换统计维度
**作为** 管理者或运营人员  
**我希望** 切换时间维度查看数据  
**以便** 对比不同周期的运营情况

**详细描述**:
- 支持按天/周/月维度切换统计数据
- 图表随时间维度变化自动更新
- 支持自定义时间范围查询

## 5. AI 问答助理

### US-013: 咨询系统使用问题
**作为** 系统用户  
**我希望** 通过 AI 助理咨询系统使用方式  
**以便** 快速上手系统功能

**详细描述**:
- AI 助理提供系统使用相关的问答服务
- 以侧边栏形式展示，不占用主界面空间
- 支持上下文对话和历史记录
