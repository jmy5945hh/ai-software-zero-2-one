# 招财银行北京分行运营门户系统 - 术语表

| 术语 | 解释 |
| --- | --- |
| 运营门户系统 | 招财银行北京分行内部用于支撑日常运营登记、审批及数据查看的统一入口系统 |
| 客户经理 | 负责客户拜访、营销活动记录及礼品申请的分行员工 |
| 运营人员 | 负责首页内容维护、新闻发布、运营数据查看的分行员工 |
| 审批人员 | 负责营销礼品申请审批的分行员工 |
| 分行管理者 | 查看全行运营数据及统计分析的分行管理人员 |
| RBAC | 基于角色的访问控制（Role-Based Access Control），一种权限管理模型 |
| 礼品台账 | 记录所有已审批礼品领用记录的台账 |
| 运营数据大屏 | 直观展示分行运营关键指标的可视化页面 |
| AI 问答助理 | 基于大模型提供通用chat问答能力的侧边栏助理 |
