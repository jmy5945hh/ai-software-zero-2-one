# 招财银行北京分行运营门户系统 - 项目总结报告

## 项目概述

招财银行北京分行运营门户系统是一个面向分行内部员工的运营支撑平台，旨在统一运营信息入口，规范客户拜访、营销活动记录，提供营销礼品审批管理，并为管理层提供运营数据可视化展示。系统引入AI问答功能，提升用户使用体验和信息获取效率。

## 项目范围

本项目成功实现了以下核心功能模块：
1. 登录与首页管理
2. 客户拜访与理财营销登记管理
3. 营销礼品领用审批管理
4. 运营数据大屏
5. AI 问答助理

## 技术架构

### 前端技术栈
- **核心框架**: React 18+
- **开发语言**: TypeScript 5.0+
- **构建工具**: Vite 5.0+
- **UI组件库**: Ant Design 5.x
- **状态管理**: Zustand
- **HTTP请求**: Axios
- **路由**: React Router v6
- **数据可视化**: ECharts 5.x

### 后端技术栈
- **核心框架**: FastAPI 0.110+
- **开发语言**: Python 3.10+
- **Web服务器**: Uvicorn
- **数据校验**: Pydantic v2
- **ORM**: SQLAlchemy 2.x
- **权限认证**: JWT
- **数据库**: MySQL 8.0+
