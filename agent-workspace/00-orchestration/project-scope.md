# 招财银行北京分行运营门户系统 - 项目范围定义

## 项目目标
建设一套分行内部运营门户系统，作为统一入口，支撑日常运营登记、审批及数据查看。

## 核心功能模块
1. 登录与首页
2. 客户拜访与理财营销登记管理
3. 营销礼品领用审批管理
4. 运营数据大屏
5. AI 问答助理（侧边栏）

## 技术栈
- 前端：React 18+, TypeScript 5.0+, Vite 5.0+, Ant Design 5.x, Zustand
- 后端：Python 3.10+, FastAPI 0.110+, SQLAlchemy 2.x
- 数据库：MySQL 8.0+
- AI：集成大模型问答能力

## 项目边界 - 本次验证目标
- 实现核心业务功能的MVP版本
- 完成前后端基础架构搭建
- 实现用户认证与权限控制
- 完成核心业务流程（客户拜访登记、礼品申请审批）
- 实现基础数据可视化

## 项目边界 - 不包含内容
- 高级性能优化
- 高级安全加固（除基础认证外）
- 移动端适配
- 第三方系统集成
- 高级AI功能（除基础问答外）

## 里程碑规划
1. 需求分析与PRD完善
2. UX设计与交互定义
3. 系统架构设计
4. 技术设计与API定义
5. 前后端开发实现
6. 测试与验证
