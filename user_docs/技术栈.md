# 技术栈

应按照本文档的前端、后端、数据库技术栈选型进行开发实现。

## 前端

分类|技术选型|版本建议|选型理由
---|---|---|---
核心框架|React|18+|生态最成熟，AI训练数据最多，生成代码准确率最高。
开发语言|TypeScript|5.0+|类型系统是AI理解业务逻辑的关键，也是后续维护的基石。
构建工具|Vite|5.0+|极速启动，配置简单，目前的标准最佳实践。
UI 组件库|Ant Design|5.x|中文B端霸主，组件丰富，文档中文极佳，覆盖你需要的所有场景。
高级业务组件|Ant Design ProComponents|最新|基于AntD的高阶封装，用“配置”代替“写代码”，大幅减少表单和表格的代码量。
数据可视化|ECharts|5.x / For React|国内可视化标准，图表丰富，中文文档完善。
流程图设计|AntV X6|最新|阿里出品，专门用于审批流、图编辑，非常适合做流程可视化。
状态管理|Zustand|最新|轻量、无模板代码，比Redux简单10倍，AI易于生成和理解。
HTTP请求|Axios|最新|经典请求库 + React Hooks工具库（含useRequest），极大简化异步逻辑。
路由|React Router|v6|单页应用标准。

## 后端

| 分类         | 技术选型                              | 版本建议   | 选型理由                                                  |
| ---------- | --------------------------------- | ------ | ----------------------------------------------------- |
| 核心框架       | FastAPI                      | 0.110+ | Python 生态中最 AI-friendly 的 Web 框架，天然支持类型、依赖注入、Swagger。 |
| 开发语言       | Python                            | 3.10+  | 类型系统成熟（typing / pydantic），AI 生成稳定。                    |
| Web Server | Uvicorn                           | 最新     | 官方推荐 ASGI Server，部署简单。                                |
| 数据校验       | Pydantic v2                       | 最新     | 强类型 = AI 可理解的数据契约。                                |
| ORM        | SQLAlchemy 2.x                    | 最新     | 声明式模型清晰，AI 生成稳定，生态最成熟。                                |
| 权限认证       | FastAPI + JWT                     | 最新     | 前后端分离标准方案。                                            |
| API 文档     | OpenAPI / Swagger                 | 内置     | AI 自检 & 人工验收核心工具。                                 |
| 异步任务       | Celery / BackgroundTasks          | 最新     | 审批流、通知、AI 调用解耦。                                       |
| 配置管理       | python-dotenv / Pydantic Settings | 最新     | 环境隔离清晰，减少“跑不起来”。                                      |


## 数据库

| 分类    | 技术选型                      | 版本建议 | 选型理由                   |
| ----- | ------------------------- | ---- | ---------------------- |
| 数据库   | MySQL               | 8.0+ | 企业级标准，JSON/CTE/窗口函数齐全。 |
| 字符集   | utf8mb4                   | 默认   | 中文 + 表情 + 扩展字段友好。      |
