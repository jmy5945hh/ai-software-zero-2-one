# 案例来源
## 仓库地址：
无，空项目
在项目路径执行git init 初始化一个git 目录

# 需求层面验收
## 功能点
1、用户、管理员权限划分
2、登录
3、查询后台Skill列表，支持检索
4、创建Skill
5、编辑Skill
6、上传或替换Skill文件
7、管理员下载
8、删除Skill
9、查看下载次数
10、查看基础操作日志
11、用户查询Skill列表，支持搜索
12、用户查看详情
13、用户下载Skill



# 技术方案层面验收
1、Java 确认框架
Spring boot + mybatis + mysql
2、接口确认风格
restful
3、鉴权方式：jwt，文档存储位置，本地
4、数据库设计
